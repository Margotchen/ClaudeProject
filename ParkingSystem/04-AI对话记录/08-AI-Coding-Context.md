# AI Coding 对话上下文记录

## 项目概述

本项目为停车位预约管理系统，基于 Vue3 + Node.js + SQLite 技术栈，采用前后端分离架构。

## 对话关键点

1. **需求确认**
   - 用户确认使用 Vue3 + Node.js + SQLite 技术栈。
   - 行业背景：企业管理场景，需考虑园区车位错峰使用。

2. **方案设计**
   - 进入 Plan Mode 进行规划。
   - 使用 Explore Agent 确认目录为空。
   - 使用 Plan Agent 设计完整实施方案。
   - 最终确定项目结构、数据库设计、API 设计、页面设计、开发顺序。

3. **开发实施**
   - 按 P0/P1 优先级分阶段实施：
     - P0 基础骨架：前后端项目初始化、登录、Layout。
     - P0 核心资源：用户、车辆、区域、车位 CRUD。
     - P0 预约与核销：预约 API、SVG 地图、核销。
     - P0 规则与风控：违约判定、封禁、系统配置。
     - P1 统计报表：Dashboard、ECharts、CSV 导出。
     - P1 测试与文档：测试用例、跑批脚本、交付文档。

4. **关键设计决策**
   - 使用 SQLite 单文件数据库，便于演示部署。
   - 使用 JWT Token + RBAC 实现角色权限。
   - 预约并发控制采用数据库事务 + 唯一约束。
   - 违约判定使用 node-cron 定时任务。
   - 统计使用每日预计算提升查询性能。
