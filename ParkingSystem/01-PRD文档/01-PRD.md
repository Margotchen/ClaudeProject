# 停车位预约管理系统 - 产品需求文档（PRD）

## 1. 项目背景

### 1.1 业务痛点

公司园区停车位资源紧张：园区仅约 200 个车位，而员工车辆超过 400 辆。当前采用"先到先得"模式，导致：
- 早高峰车位一位难求，员工开车到园区后绕场寻找车位，浪费时间；
- 无法提前规划出行方式，降低通勤效率；
- 固定车位、访客车位、充电车位缺乏统一管理；
- 违约成本低，预约后未到场的情况无法约束。

### 1.2 目标

建设一套园区停车位预约管理系统，实现：
- 错峰预约，提升车位周转率；
- 可视化车位地图，实时掌握空闲状态；
- 入场核销，确保预约资源真实使用；
- 违约风控，约束不文明预约行为；
- 多角色权限，支持员工、车位管理员、系统管理员协同管理。

## 2. 用户与角色

| 角色 | 职责 | 数据范围 |
|------|------|----------|
| 员工 | 登记车辆、预约车位、核销入场、查看个人预约 | 仅个人数据 |
| 车位管理员 | 车位维护、违约处理、预约核销、统计查看 | 全部车位与预约数据 |
| 系统管理员 | 用户管理、系统配置、操作日志、全部功能 | 全量数据 |

## 3. 功能需求

### 3.1 车位信息管理

- 维护车位编号、所属区域、车位类型、物理状态；
- 支持固定车位绑定所有者；
- 支持车位维护状态标记；
- 批量初始化 200 个车位（A/B/C/D 四区各 50 个）。

### 3.2 车位地图可视化

- 以 SVG 平面示意图展示 A/B/C/D 四区车位分布；
- 按日期和时段（上午/下午/全天）展示空闲/占用状态；
- 点击空闲车位可发起预约；
- 图例区分：空闲、已占用、固定车位、充电车位、访客车位。

### 3.3 车位预约

- 员工选择日期与时段预约空闲车位；
- 同一日期同一时段只能有一个有效预约；
- 普通员工最多提前 3 天预约，管理员可配置更长窗口；
- 固定车位仅所有者或管理员可预约；
- 维护中车位不可预约。

### 3.4 车辆信息管理

- 员工登记车牌号、车型、颜色；
- 一人可登记多辆车，支持设置默认车辆；
- 车牌号唯一性校验；
- 存在有效预约的车辆不可删除。

### 3.5 入场核销

- 支持预约单扫码核销、车牌号核销、管理员手动核销；
- 员工仅可核销自己的预约；
- 车位管理员/系统管理员可代为核销；
- 预约时段开始前 30 分钟可开始核销。

### 3.6 违约记录

- 预约开始后 15 分钟未核销，自动标记为违约；
- 累计 3 次违约自动封禁 7 天；
- 封禁期满后可自动恢复；
- 车位管理员可对违约记录进行减免。

### 3.7 使用统计

- 总车位、今日预约、有效预约、今日核销、本月违约等概览指标；
- 各区域使用率柱状图；
- 近 7 日各时段预约趋势折线图；
- 详细数据表格与 CSV 导出。

### 3.8 用户登录与权限

- 基于 JWT Token 的登录鉴权；
- 基于角色的菜单与按钮权限控制；
- 默认账号：admin（系统管理员）、manager（车位管理员）、employee1（员工）。

## 4. 业务流程

### 4.1 预约流程

```
员工登录 -> 选择日期/时段 -> 查看车位地图 -> 点击空闲车位 -> 选择车辆 -> 确认预约 -> 系统校验规则 -> 生成预约单
```

### 4.2 核销流程

```
员工驾车到达 -> 扫码/输入车牌/管理员手动核销 -> 系统校验预约与时段 -> 更新为已核销 -> 入场停车
```

### 4.3 违约处理流程

```
定时任务扫描 -> 发现超时未核销 -> 标记违约 -> 增加用户违约次数 -> 达到 3 次封禁 7 天 -> 发送通知/记录日志
```

## 5. 用户场景

### 场景一：日常通勤预约

张三每天开车上班，前一天晚上登录系统，预约第二天上午的共享车位，第二天到达后扫码核销入场。

### 场景二：临时访客停车

行政部为来访客户提前在系统中查看访客车位空闲情况，或引导访客使用访客车位区域。

### 场景三：车位维护

车位管理员发现 A012 车位地面损坏，将该车位状态改为"维护中"，员工在地图上看到后无法预约。

### 场景四：违约处理

李四连续 3 次预约后未到场，系统自动封禁其预约权限 7 天；期满后李四可正常预约。

## 6. 非功能需求

- 并发控制：同一车位同一时段在高并发下只能成功预约一次；
- 性能：200 车位 × 30 天统计查询 < 3 秒；
- 安全：密码加密存储，JWT 鉴权，操作日志审计；
- 易用性：界面简洁，移动端适配基础布局。
