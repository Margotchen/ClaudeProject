# 在线商城订单管理系统 - 需求规格说明书

------

## 01 项目概述

### 1.1 项目背景

某电商公司需建设一套完整的在线商城订单管理系统，覆盖从商品展示、用户下单、支付履约、物流配送到售后服务的全订单生命周期管理，实现业务流程数字化与标准化。

本项目基于开源项目 `macrozheng/mall` 进行改造：后端复用其 Spring Boot + MyBatis 架构，前端复用其 Vue3 + Element Plus 管理后台，并在此基础上补充商家角色、数据权限隔离、订单状态机细化等需求。

### 1.2 项目目标

- 实现订单全流程线上化管理，提升交易处理效率
- 基于角色权限实现多端数据隔离与操作管控
- 提供可视化数据统计与报表导出能力，支撑运营决策
- 采用前后端分离架构，保证系统可扩展性与可维护性

### 1.3 适用角色

表格

| 角色       | 权限范围                 | 核心操作                                           |
| ---------- | ------------------------ | -------------------------------------------------- |
| 普通用户   | 仅查看与操作自身数据     | 浏览商品、购物车管理、下单支付、查看物流、发起售后 |
| 商家       | 管理自身店铺商品与订单数据 | 通过平台管理后台登录，仅可见自身店铺数据；可执行商品上架 / 维护、订单处理、发货登记、售后审核 |
| 平台管理员 | 全平台数据查看与统计权限 | 订单全局查询、经营数据统计、报表导出、系统配置     |

## 02 业务功能需求

### 2.1 商品管理模块

- **基础信息维护**：支持商品名称、分类、单价、库存数量、主图、详情描述的增删改查
- **多规格管理**：支持按颜色、尺寸等维度设置商品 SKU，每个 SKU 独立维护价格与库存
- **上下架控制**：商家可控制商品上架 / 下架状态，下架商品不在前端展示
- **分类管理**：支持多级商品分类，用于商品归类与统计筛选

### 2.2 购物车模块

- **加入购物车**：用户选择商品规格与数量后加入购物车
- **购物车编辑**：支持修改商品数量、删除单品、清空购物车
- **选中结算**：支持勾选部分商品进行结算，未勾选商品保留在购物车
- **库存校验**：结算时实时校验商品库存，库存不足时提示用户

### 2.3 订单管理模块

#### 2.3.1 订单创建

- 从购物车选中商品结算生成订单
- 订单包含信息：收货地址（联系人、电话、详细地址）、商品明细（SKU、数量、单价、小计）、订单总金额、优惠抵扣信息、下单时间
- 订单生成后扣减对应商品库存，生成唯一订单号

#### 2.3.2 订单状态机

系统定义 8 种核心订单状态，支持状态间合规流转：

1. **待支付**：订单创建后初始状态，等待用户付款
2. **已支付**：支付成功后自动流转，等待商家发货
3. **待发货**：商家确认收款后，待录入物流信息
4. **已发货**：商家填写物流信息后，订单标记为发货状态
5. **已收货**：用户确认收货后流转
6. **已完成**：收货后超过售后期或无售后，订单完结
7. **已取消**：待支付状态下用户取消，或支付超时自动取消
8. **售后中**：用户发起退款 / 退货申请后进入该状态

#### 2.3.3 发货管理

- 商家端：填写物流公司名称、物流运单号，确认发货
- 用户端：查看物流公司、运单号、物流轨迹（模拟展示）
- 发货后订单状态自动变更为「已发货」

#### 2.3.4 售后管理

- 用户发起：支持退款、退货两种售后类型，需填写售后原因、上传凭证图片
- 商家处理：支持审核通过、审核驳回操作，填写处理意见
- 状态联动：售后发起后订单进入「售后中」，售后完结后订单流转至对应终态

### 2.4 支付对接模块

- 提供模拟支付接口，支持调用支付网关
- 支持支付成功回调：更新订单状态为「已支付」，记录支付流水
- 支持支付失败回调：保留订单为「待支付」，返回失败原因
- 支持支付超时自动取消订单，释放对应库存

### 2.5 用户与权限模块

- 基于角色的访问控制（RBAC），支持用户 / 商家 / 管理员三种角色
- 统一登录鉴权，不同角色登录后展示不同菜单与数据范围
- 用户仅可见自身订单与售后数据；商家仅可见自身店铺商品与订单；管理员可见全平台数据
- 支持账号密码登录，接口请求携带 Token 鉴权

### 2.6 统计报表模块

#### 2.6.1 数据统计维度

- 按时间维度：日 / 周 / 月 / 自定义区间统计销售额、订单量、客单价
- 按商品维度：统计单个商品的销量、销售额、退款率
- 按类目维度：按商品分类统计销售占比与订单分布

#### 2.6.2 看板与导出

- 管理后台提供统计看板，包含数据表格与可视化图表（柱状图、折线图、饼图）
- 支持统计数据导出为 Excel / CSV 格式文件

## 03 技术方案

### 3.1 整体架构

采用**前后端分离**架构，前端负责页面交互与数据展示，后端提供业务逻辑与数据服务，前后端通过 RESTful API 进行通信，基于 Token 实现接口鉴权。

### 3.2 技术栈选型

表格

| 层级     | 选型                              | 说明                                      |
| -------- | --------------------------------- | ----------------------------------------- |
| 前端     | Vue3 + Element Plus               | 基于 `macrozheng/mall-admin-web` 改造     |
| 后端     | Spring Boot + MyBatis-Plus        | 基于 `macrozheng/mall` 改造               |
| 数据库   | MySQL 8.0                         | 关系型数据库，存储业务数据                |
| 缓存     | Redis（可选）                     | 会话、热点数据缓存                        |
| 消息队列 | RabbitMQ（可选）                  | 异步通知、延迟消息                        |
| 接口协议 | RESTful API                       | 统一 HTTP 接口，JSON 格式交互             |
| 鉴权方式 | JWT Token                         | 登录后签发 Token，接口请求携带校验        |

### 3.3 核心数据表设计

1. **用户表**：用户 ID、账号、密码哈希、角色、昵称、联系方式
2. **商品分类表**：分类 ID、分类名称、父分类 ID、排序
3. **商品表**：商品 ID、商品名称、分类 ID、主图、详情、上下架状态
4. **商品 SKU 表**：SKU_ID、商品 ID、规格属性（颜色 / 尺寸）、价格、库存
5. **购物车表**：购物车 ID、用户 ID、SKU_ID、数量、选中状态
6. **订单表**：订单号、用户 ID、收货信息、总金额、优惠金额、订单状态、下单时间、支付时间、发货时间、收货时间
7. **订单明细表**：明细 ID、订单号、SKU_ID、商品名称、规格、单价、数量、小计
8. **物流表**：物流 ID、订单号、物流公司、运单号、发货时间
9. **售后表**：售后 ID、订单号、售后类型、售后原因、凭证、状态、处理意见、申请时间
10. **支付流水表**：流水 ID、订单号、支付金额、支付状态、回调时间

### 3.4 接口规范

- 所有接口遵循 RESTful 设计风格，使用标准 HTTP 方法（GET/POST/PUT/DELETE）
- 接口统一返回格式：`{ code, message, data }`
- 需鉴权接口请求头携带 `Authorization: Bearer {token}`
- 统一异常处理与错误码定义

### 3.6 开源基础项目

- **后端基础**：`macrozheng/mall`（https://github.com/macrozheng/mall）
  - Spring Boot + MyBatis + MySQL
  - 提供商品、订单、购物车、支付、售后、RBAC、统计报表等完整模块
- **前端基础**：`macrozheng/mall-admin-web`（https://github.com/macrozheng/mall-admin-web）
  - Vue3 + Element Plus
  - 提供管理后台基础界面和权限菜单

改造重点：新增商家角色与店铺模型、订单状态机细化、售后状态联动、支付超时自动取消、数据权限隔离。

### 3.7 前端访问入口

系统提供两套独立的前端入口，分别面向 C 端买家与 B 端商家 / 管理员。开发环境下前端 dev server 默认运行在 `http://localhost:5173`，生产环境地址以实际部署为准。

| 入口         | 路径                 | 说明                                            |
| ------------ | -------------------- | ----------------------------------------------- |
| 商家 / 管理员登录 | `/login`             | 使用 `mall-admin-web` 后台账号登录               |
| 买家登录     | `/buyer/login`       | 使用 `mall-portal` 会员账号登录                  |
| 买家注册     | `/buyer/register`    | 新用户注册，需填写手机号并获取短信验证码         |
| 商城首页     | `/buyer/index`       | 商品推荐、分类浏览                              |
| 商品详情     | `/buyer/product/:id` | 查看 SKU 规格、价格、库存并加入购物车            |
| 购物车       | `/buyer/cart`        | 管理已加购商品，选择商品后结算                   |
| 订单确认     | `/buyer/order/confirm` | 确认收货地址、商品明细后提交订单                 |
| 订单列表     | `/buyer/order/list`  | 查看买家全部订单及状态                          |
| 个人中心     | `/buyer/profile`     | 查看 / 修改会员信息                             |

说明：

- 买家入口与后台入口使用独立的 JWT Token，分别由 `mall-portal`（端口 8085）和 `mall-admin`（端口 8080）签发，避免鉴权串扰。
- 未登录买家访问 `/buyer/login`、`/buyer/register`、`/buyer/index` 之外的买家路由时，会自动跳转至 `/buyer/login`。
- 商家 / 管理员通过 `/login` 登录后进入管理后台；已登录商家 / 管理员访问买家入口可正常浏览，但操作购物车、下单等需买家 Token 的接口时会提示登录。

## 04 输入输出定义

### 4.1 系统输入

1. 商品信息：商品基础属性、多规格参数、库存与价格数据
2. 购物车操作：加购、修改数量、删除、选中 / 取消选中
3. 订单信息：收货地址、结算商品清单、优惠信息
4. 支付回调：支付结果通知（成功 / 失败）、支付金额、交易流水号
5. 售后申请：售后类型、原因说明、凭证图片
6. 发货信息：物流公司名称、物流运单号
7. 统计查询：时间范围、商品 ID、分类 ID 等筛选条件

### 4.2 系统输出

1. 商品列表：分页商品数据、分类筛选结果、商品详情与规格信息
2. 购物车：当前用户购物车商品列表、选中商品总价
3. 订单列表：按状态筛选的订单列表、订单分页数据
4. 订单详情：订单基础信息、商品明细、金额明细、状态流转记录
5. 物流信息：物流公司、运单号、物流轨迹信息
6. 售后单：售后详情、处理状态、商家处理意见
7. 统计报表：销售额、订单量、客单价等统计数据，表格与图表展示，支持导出文件

## 05 非功能需求

1. **数据一致性**：订单创建、支付、发货、售后各环节保证库存与订单状态数据一致
2. **安全性**：密码加密存储，接口鉴权，敏感数据脱敏展示
3. **可扩展性**：模块化设计，支持后续扩展营销活动、优惠券等功能
4. **易用性**：操作流程符合电商用户习惯，后台管理界面简洁高效
