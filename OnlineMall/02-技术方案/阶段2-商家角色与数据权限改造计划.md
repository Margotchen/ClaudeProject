# 阶段 2：商家角色与数据权限改造计划

> **面向 AI 代理的工作者：** 本阶段为后续所有商家相关功能奠定基础。完成后，平台管理员可查看全平台数据，商家登录后只能查看自己店铺的商品与订单。

**目标：** 新增商家模型与角色，扩展用户、商品、订单表，实现基于 `shop_id` 的数据权限隔离。

**架构：** 新增 `ums_merchant` 商家表，通过 `shop_id` 将管理员账号、商品、订单关联到商家；在 Service/Mapper 层统一附加 `shop_id` 过滤条件。

**技术栈：** Spring Boot + MyBatis + MySQL + Spring Security + JWT。

### 步骤 1：新增获取当前商家 shop_id 的工具方法

新建 `05-项目源代码/backend/mall-admin/src/main/java/com/macro/mall/util/CurrentMerchantUtil.java`：

```java
package com.macro.mall.util;

import com.macro.mall.bo.AdminUserDetails;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;

public class CurrentMerchantUtil {
    public static Long getCurrentShopId() {
        Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
        if (authentication != null && authentication.getPrincipal() instanceof AdminUserDetails) {
            AdminUserDetails details = (AdminUserDetails) authentication.getPrincipal();
            return details.getUmsAdmin().getMerchantId();
        }
        return null;
    }

    public static boolean isPlatformAdmin() {
        return getCurrentShopId() == null;
    }
}
```
