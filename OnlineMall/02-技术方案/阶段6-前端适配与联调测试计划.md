# 阶段 6：前端适配与联调测试计划

> **面向 AI 代理的工作者：** 本阶段完成前端所有改造点，与后端接口联调，并输出完整测试报告。

**目标：** 前端支持商家/管理员双角色登录、商家菜单过滤、商品/订单/售后/统计页面改造，完成端到端联调。

**架构：** 基于 `mall-admin-web` 扩展权限控制、新增商家管理页面、调整商品/订单/售后页面，统一调用后端改造后的接口。

**技术栈：** Vue3 + Element Plus + Vite + Pinia + Axios + ECharts。

### 步骤 1：扩展 User Store

在 `user.js` 中新增 `shopId` 和 `merchantId`：

```javascript
const state = {
  token: getToken(),
  name: '',
  avatar: '',
  roles: [],
  shopId: null,
  merchantId: null
}

const mutations = {
  // ...
  SET_SHOP_ID: (state, shopId) => {
    state.shopId = shopId
  },
  SET_MERCHANT_ID: (state, merchantId) => {
    state.merchantId = merchantId
  }
}

const actions = {
  GetInfo({ commit, state }) {
    return new Promise((resolve, reject) => {
      getInfo().then(response => {
        const data = response.data
        commit('SET_ROLES', data.roles)
        commit('SET_NAME', data.username)
        commit('SET_AVATAR', data.icon)
        commit('SET_SHOP_ID', data.shopId)
        commit('SET_MERCHANT_ID', data.merchantId)
        resolve(data)
      }).catch(error => {
        reject(error)
      })
    })
  }
}
```
