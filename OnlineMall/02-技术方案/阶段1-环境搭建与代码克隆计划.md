# 阶段 1：环境搭建与代码克隆实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将 `macrozheng/mall` 后端与 `mall-admin-web` 前端克隆到项目指定目录，完成 MySQL 数据库初始化，并成功启动前后端服务验证环境可用。

**架构：** 基于 `macrozheng/mall` 开源电商系统，使用 Spring Boot 后端 + Vue3 Element Plus 前端，MySQL 作为关系型数据库。本阶段只完成基础环境搭建，不涉及业务改造。

**技术栈：** Spring Boot、Vue3、Element Plus、MySQL、Maven、Node.js

## 常见问题

1. **MySQL 连接失败**：检查 MySQL 服务是否启动，用户名密码是否正确。
2. **端口冲突**：后端默认 8080，前端默认 8090，若被占用需修改配置。
3. **Maven 下载依赖慢**：可配置阿里云 Maven 镜像。
4. **npm install 失败**：检查 Node.js 版本，建议使用 18+，可尝试 `npm install --registry=https://registry.npmmirror.com`。
