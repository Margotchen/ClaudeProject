# 阶段 3：订单状态机与支付超时改造计划

> **面向 AI 代理的工作者：** 本阶段将 mall 原有的订单状态改造为 PRD 要求的 8 种状态，并实现支付成功/失败回调、支付超时自动取消。

**目标：** 统一订单状态枚举为 8 种状态，改造状态流转逻辑，增加支付流水记录与超时取消定时任务。

**架构：** 在 `mall-admin` 中新增 `OmsPayment` 支付流水表与 `OmsOrderStatusMachine` 状态机工具类；通过 Spring Scheduler 扫描待支付订单并自动取消。

**技术栈：** Spring Boot + MyBatis + MySQL + Spring Scheduler。

### 步骤 1：明确 8 种订单状态

```
0: 待支付 (PENDING_PAY)
1: 已支付 (PAID)
2: 待发货 (PENDING_SHIP)
3: 已发货 (SHIPPED)
4: 已收货 (RECEIVED)
5: 已完成 (COMPLETED)
6: 已取消 (CANCELLED)
7: 售后中 (AFTER_SALE)
```

mall 原状态字段 `status` 已有的值需要映射：
- 原 0: 待付款 → 新 0: 待支付
- 原 1: 待发货 → 新 2: 待发货
- 原 2: 已发货 → 新 3: 已发货
- 原 3: 已完成 → 新 5: 已完成
- 原 4: 已关闭 → 新 6: 已取消
- 原 5: 无效订单 → 新 6: 已取消

### 步骤 1：创建 `OrderStatusEnum.java`

```java
package com.macro.mall.enums;

import lombok.Getter;

@Getter
public enum OrderStatusEnum {
    PENDING_PAY(0, "待支付"),
    PAID(1, "已支付"),
    PENDING_SHIP(2, "待发货"),
    SHIPPED(3, "已发货"),
    RECEIVED(4, "已收货"),
    COMPLETED(5, "已完成"),
    CANCELLED(6, "已取消"),
    AFTER_SALE(7, "售后中");

    private final int value;
    private final String label;

    OrderStatusEnum(int value, String label) {
        this.value = value;
        this.label = label;
    }

    public static OrderStatusEnum of(int value) {
        for (OrderStatusEnum e : values()) {
            if (e.value == value) return e;
        }
        throw new IllegalArgumentException("Unknown order status: " + value);
    }
}
```

### 步骤 2：创建 `OrderStatusMachine.java`

```java
package com.macro.mall.util;

import com.macro.mall.enums.OrderStatusEnum;

import java.util.*;

public class OrderStatusMachine {
    private static final Map<OrderStatusEnum, Set<OrderStatusEnum>> TRANSITIONS = new EnumMap<>(OrderStatusEnum.class);

    static {
        TRANSITIONS.put(OrderStatusEnum.PENDING_PAY, Set.of(OrderStatusEnum.PAID, OrderStatusEnum.CANCELLED));
        TRANSITIONS.put(OrderStatusEnum.PAID, Set.of(OrderStatusEnum.PENDING_SHIP, OrderStatusEnum.AFTER_SALE));
        TRANSITIONS.put(OrderStatusEnum.PENDING_SHIP, Set.of(OrderStatusEnum.SHIPPED, OrderStatusEnum.AFTER_SALE));
        TRANSITIONS.put(OrderStatusEnum.SHIPPED, Set.of(OrderStatusEnum.RECEIVED, OrderStatusEnum.AFTER_SALE));
        TRANSITIONS.put(OrderStatusEnum.RECEIVED, Set.of(OrderStatusEnum.COMPLETED, OrderStatusEnum.AFTER_SALE));
        TRANSITIONS.put(OrderStatusEnum.AFTER_SALE, Set.of(OrderStatusEnum.COMPLETED, OrderStatusEnum.CANCELLED));
    }

    public static boolean canTransition(int fromStatus, int toStatus) {
        OrderStatusEnum from = OrderStatusEnum.of(fromStatus);
        OrderStatusEnum to = OrderStatusEnum.of(toStatus);
        return canTransition(from, to);
    }

    public static boolean canTransition(OrderStatusEnum from, OrderStatusEnum to) {
        if (from == to) return true;
        Set<OrderStatusEnum> allowed = TRANSITIONS.get(from);
        return allowed != null && allowed.contains(to);
    }
}
```

### 步骤 1：新增订单取消方法

```java
 * 取消超时未支付订单
 */

```

实现逻辑：
- 查询 `status = 0` 且 `create_time < deadline` 的订单
- 将状态更新为 6（已取消）
- 恢复对应 SKU 库存

### 步骤 2：创建定时任务

```java
package com.macro.mall.component;

import com.macro.mall.service.OmsOrderService;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

import java.util.Date;

@Component
public class OrderTimeoutCancelTask {
    private static final Logger LOGGER = LoggerFactory.getLogger(OrderTimeoutCancelTask.class);
    @Autowired
    private OmsOrderService orderService;

    /**
     * 每 10 分钟扫描一次，取消超过 30 分钟未支付的订单
     */
    @Scheduled(cron = "0 0/10 * * * ?")
    public void cancel() {
        long deadlineMillis = System.currentTimeMillis() - 30 * 60 * 1000;
        Date deadline = new Date(deadlineMillis);
        int count = orderService.cancelTimeoutOrders(deadline);
        LOGGER.info("取消超时未支付订单数量：{}", count);
    }
}
```

```java
public int cancelOrder(Long orderId) {
```
