# 线上机票预订系统需求文档

## 1. 项目概述

### 1.1 项目背景
为航空公司建设一套前后端分离的线上机票预订系统，覆盖航班管理、机票查询、在线预订、模拟支付、选座值机、退改签、电子行程单、航班动态、角色权限与统计报表等核心业务流程。

### 1.2 目标用户
- 旅客（Passenger）：查询航班、下单购票、支付、选座值机、退改签、下载行程单。
- 客服（Service）：处理旅客退改签申请、查询旅客订单。
- 运营人员（Operator）：维护航班与排班、更新航班动态、查看统计看板与导出数据。

### 1.3 运行环境
- 前端：Vue 3 + Vite + Element Plus，运行在浏览器端。
- 后端：Node.js + Express + SQLite，提供 RESTful API。
- 部署：本地开发环境或单机服务器。

## 2. 功能需求

### 2.1 用户认证与权限
- 使用 cookie-session 登录，区分 passenger/service/operator 三种角色。
- 角色路由守卫：无权限时自动跳转。

### 2.2 航班管理
- 运营端维护航班（航班号、起降机场、计划时长）。
- 运营端维护排班（日期、起降时间、机型、各舱位票价、余座）。
- 运营端更新航班状态：正常、延误、取消。

### 2.3 机票查询
- 旅客按出发城市、目的城市、日期查询航班。
- 结果展示航班号、起降时间、机型、各舱位票价与余座。

### 2.4 在线预订
- 选择舱位、填写乘机人与联系人，生成待支付订单。
- 创建订单时锁定并扣减对应舱位库存。

### 2.5 模拟支付
- 模拟支付成功后订单变为已出票状态，自动生成电子客票。
- 支付失败保留待支付状态。

### 2.6 选座与值机
- 根据机型布局渲染座位图。
- 为每位乘机人选择座位；值机仅在起飞前 24 小时内开放。
- 值机成功后客票状态变为已值机。

### 2.7 退改签
- 退票：按起飞前时间计算退款比例（>24h 退 90%，2-24h 退 70%，<2h 不退）。
- 改签：选择同航线目标航班，按舱位收取手续费并多退少补。
- 客服端审核通过后执行退改。

### 2.8 行程单 PDF
- 已支付订单可生成 PDF 行程单，包含航班、乘机人、票号、座位、金额、交易号。

### 2.9 航班动态与通知
- 公开查询航班动态。
- 航班延误或取消时自动给受影响订单用户发送站内通知。

### 2.10 统计看板与导出
- 运营端看板：今日航班数、今日订单数、今日销售额、待处理退改签数。
- 图表：近 7 日订单趋势、舱位销售占比、热门航线 Top 5。
- 导出订单/航班 Excel 与 CSV。

## 3. 非功能需求

- 响应速度：页面首屏加载不超过 3 秒，接口响应不超过 1 秒。
- 并发：单机支持不少于 50 并发下单。
- 安全：密码 bcrypt 加密；服务端 session 鉴权；SQL 注入由 ORM 参数化防护。
- 可维护：采用 MVC 分层、统一响应格式、统一错误处理。

## 5. 术语表

- 航班（Flight）：固定航线与航班号的航线定义。
- 排班（Schedule）：航班在具体日期的执行计划。
- 舱位（Cabin）：economy / business / first。
- 订单状态：待支付、已支付、已出票、已值机、已改签、已退票、已取消。
