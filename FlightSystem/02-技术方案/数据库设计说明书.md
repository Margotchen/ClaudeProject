# 数据库设计说明书

## 1. 概述

数据库采用 SQLite，通过 Sequelize ORM 进行访问。数据库文件位于 `flight-system-backend/data/` 目录下。

## 2. ER 关系

- `sys_role` 1:N `sys_user`
- `airport` 1:N `flight`（departure / arrival）
- `aircraft` 1:N `flight_schedule`
- `flight` 1:N `flight_schedule`
- `flight_schedule` 1:N `seat_inventory`
- `flight_schedule` 1:N `order`
- `sys_user` 1:N `order`
- `order` 1:N `order_passenger`
- `order` 1:N `payment`
- `order` 1:N `refund_change`
- `order_passenger` 1:1 `ticket`
- `flight_schedule` 1:N `ticket`
- `ticket` 1:1 `seat_selection`
- `flight_schedule` 1:1 `flight_status`
- `sys_user` 1:N `notification`

## 3. 表结构

### 3.1 sys_role

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 角色 ID |
| role_code | VARCHAR(32) UNIQUE | 角色编码：passenger/service/operator |
| role_name | VARCHAR(64) | 角色名称 |
| description | TEXT | 描述 |
| create_time | DATETIME | 创建时间 |

### 3.2 sys_user

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 用户 ID |
| username | VARCHAR(64) UNIQUE | 登录账号 |
| password | VARCHAR(255) | bcrypt 哈希 |
| real_name | VARCHAR(64) | 真实姓名 |
| phone | VARCHAR(32) | 手机号 |
| id_card | VARCHAR(32) | 身份证号 |
| role_id | INTEGER FK | 角色 |
| status | TINYINT | 0 禁用 / 1 启用 |
| create_time | DATETIME | 创建时间 |

### 3.3 airport

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 机场 ID |
| airport_code | VARCHAR(8) UNIQUE | 机场代码 |
| airport_name | VARCHAR(128) | 机场名称 |
| city_name | VARCHAR(64) | 城市 |

### 3.4 aircraft

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 机型 ID |
| model | VARCHAR(64) | 机型名称 |
| total_seats | INTEGER | 总座位数 |
| layout | TEXT | 座位布局 JSON |

layout 示例：
```json
{
  "first": { "rows": 4, "cols": 4, "startRow": 1, "letters": ["A","B","C","D"] },
  "business": { "rows": 4, "cols": 4, "startRow": 5 },
  "economy": { "rows": 25, "cols": 6, "startRow": 11 }
}
```

### 3.5 flight

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 航班 ID |
| flight_no | VARCHAR(16) UNIQUE | 航班号 |
| departure_airport_id | INTEGER FK | 出发机场 |
| arrival_airport_id | INTEGER FK | 到达机场 |
| planned_duration | INTEGER | 计划飞行时长（分钟） |

### 3.6 flight_schedule

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 排班 ID |
| flight_id | INTEGER FK | 航班 |
| aircraft_id | INTEGER FK | 机型 |
| flight_date | DATE | 日期 |
| departure_time | DATETIME | 计划起飞 |
| arrival_time | DATETIME | 计划到达 |
| economy_price | DECIMAL(10,2) | 经济舱价格 |
| business_price | DECIMAL(10,2) | 商务舱价格 |
| first_price | DECIMAL(10,2) | 头等舱价格 |
| status | TINYINT | 0 计划 / 1 正常 / 2 延误 / 3 取消 |
| delay_minutes | INTEGER | 延误分钟 |

### 3.7 seat_inventory

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| schedule_id | INTEGER FK | 排班 |
| cabin_class | VARCHAR(16) | 舱位 |
| available_seats | INTEGER | 余座 |
| total_seats | INTEGER | 总座 |

唯一索引：`(schedule_id, cabin_class)`

### 3.8 `order`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| order_no | VARCHAR(32) UNIQUE | 订单号 |
| user_id | INTEGER FK | 用户 |
| schedule_id | INTEGER FK | 排班 |
| cabin_class | VARCHAR(16) | 舱位 |
| total_amount | DECIMAL(10,2) | 总金额 |
| status | TINYINT | 0 待支付 / 1 已支付 / 2 已出票 / 3 已值机 / 4 已改签 / 5 已退票 / 6 已取消 |
| contact_name | VARCHAR(64) | 联系人 |
| contact_phone | VARCHAR(32) | 联系电话 |
| pay_time | DATETIME | 支付时间 |
| create_time | DATETIME | 创建时间 |

### 3.9 order_passenger

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| order_id | INTEGER FK | 订单 |
| name | VARCHAR(64) | 姓名 |
| id_card | VARCHAR(32) | 身份证 |
| ticket_no | VARCHAR(32) UNIQUE | 票号 |

### 3.10 payment

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| order_id | INTEGER FK | 订单 |
| amount | DECIMAL(10,2) | 金额 |
| pay_method | VARCHAR(32) | 支付方式 |
| pay_status | TINYINT | 0 失败 / 1 成功 |
| transaction_no | VARCHAR(64) | 流水号 |
| pay_time | DATETIME | 支付时间 |
| create_time | DATETIME | 创建时间 |

### 3.11 ticket

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| ticket_no | VARCHAR(32) UNIQUE | 票号 |
| order_passenger_id | INTEGER FK | 乘客 |
| schedule_id | INTEGER FK | 排班 |
| cabin_class | VARCHAR(16) | 舱位 |
| seat_no | VARCHAR(8) | 座位号 |
| status | TINYINT | 0 未使用 / 1 已值机 / 2 已改签 / 3 已退票 / 4 已使用 |

### 3.12 seat_selection

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| ticket_id | INTEGER FK | 客票 |
| seat_no | VARCHAR(8) | 座位号 |
| select_time | DATETIME | 选座时间 |

### 3.13 refund_change

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| order_id | INTEGER FK | 订单 |
| type | TINYINT | 1 退票 / 2 改签 |
| reason | TEXT | 原因 |
| fee | DECIMAL(10,2) | 手续费 |
| refund_amount | DECIMAL(10,2) | 退款/差价金额 |
| target_schedule_id | INTEGER FK | 改签目标排班 |
| status | TINYINT | 0 待审核 / 1 已通过 / 2 已拒绝 |
| apply_time | DATETIME | 申请时间 |

### 3.14 flight_status

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| schedule_id | INTEGER FK | 排班 |
| status | TINYINT | 1 正常 / 2 延误 / 3 取消 |
| delay_minutes | INTEGER | 延误分钟 |
| reason | VARCHAR(255) | 原因 |
| update_time | DATETIME | 更新时间 |

### 3.15 notification

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | ID |
| user_id | INTEGER FK | 用户 |
| title | VARCHAR(128) | 标题 |
| content | TEXT | 内容 |
| is_read | TINYINT | 0 未读 / 1 已读 |
| create_time | DATETIME | 创建时间 |

## 4. 索引

```sql
CREATE INDEX idx_flight_airports ON flight(departure_airport_id, arrival_airport_id);
CREATE INDEX idx_schedule_flight_date ON flight_schedule(flight_id, flight_date);
CREATE UNIQUE INDEX idx_schedule_cabin ON seat_inventory(schedule_id, cabin_class);
CREATE INDEX idx_order_user ON `order`(user_id, status);
CREATE INDEX idx_ticket_passenger ON ticket(order_passenger_id);
CREATE INDEX idx_notification_user ON notification(user_id, is_read);
```
