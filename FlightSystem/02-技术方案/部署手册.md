# 部署手册

## 1. 环境要求

- Node.js 24+（需支持 native module 编译，或直接使用 better-sqlite3 13 预构建版本）
- npm 10+
- 现代浏览器（Chrome / Edge / Firefox）

## 2. 目录说明

```
FlightSystem/
├── 01-PRD文档/
├── 02-技术方案/
├── 03-测试报告/
├── 04-AI对话记录/
└── 05-项目源代码/
    ├── flight-system-backend/
    └── flight-system-frontend/
```

## 3. 后端部署

### 3.1 安装依赖

```bash
cd 05-项目源代码/flight-system-backend
npm install
```

### 3.2 配置环境变量

复制 `.env.example` 为 `.env`（如不存在则创建）：

```bash
PORT=3000
NODE_ENV=development
SESSION_SECRET=your_secret_key_here
```

### 3.3 初始化数据库

```bash
npm run db:init
```

该命令会同步表结构并写入初始测试数据。

### 3.4 启动服务

开发模式：

```bash
npm run dev
```

生产模式：

```bash
npm start
```

服务默认监听 `http://localhost:3000`。

## 4. 前端部署

### 4.1 安装依赖

```bash
cd 05-项目源代码/flight-system-frontend
npm install
```

### 4.2 开发运行

```bash
npm run dev
```

默认地址 `http://localhost:5173`，已通过 Vite proxy 代理到 `http://localhost:3000/api`。

### 4.3 生产构建

```bash
npm run build
```

构建产物位于 `dist/` 目录。

## 5. 验证

1. 浏览器访问 `http://localhost:5173/login`。
2. 使用测试账号登录：
   - passenger / pass123
   - service / svc123
   - operator / op123
3. 根据角色访问对应菜单并验证业务流程。

## 6. 常见问题

### 6.1 better-sqlite3 安装失败
- 确保 Node.js 版本与 better-sqlite3 预构建版本匹配（当前使用 13.0.3）。
- 如仍失败，可尝试 `npm install better-sqlite3 --build-from-source`，需 Python 与 C++ 构建工具。

### 6.2 跨域问题
- 开发环境通过 Vite proxy 解决。
- 生产环境需将前端构建产物部署到与后端同域，或配置后端 CORS 允许前端域名。

### 6.3 数据库重置

```bash
npm run db:init
```

注意：该脚本使用 `force: true` 同步，会清空现有数据。

## 7. 生产部署建议

- 使用 pm2 或 systemd 管理 Node 进程。
- 使用 Nginx 反向代理静态文件与 API。
- 将 session 存储从内存改为 Redis 或数据库存储，以支持多实例部署。
- 定期备份 `data/` 目录下的 SQLite 数据库文件。
