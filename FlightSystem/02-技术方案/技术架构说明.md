# 技术架构说明

## 1. 总体架构

系统采用前后端分离架构：

```
┌─────────────────────┐      HTTP / REST / Cookie       ┌─────────────────────┐
│   Vue 3 前端         │  <──────────────────────────>  │   Express 后端      │
│  Vite + Element Plus │      withCredentials: true     │  better-sqlite3 /   │
│   Pinia + Vue Router │                                 │  Sequelize / PDF    │
└─────────────────────┘                                 └─────────────────────┘
```

## 2. 前端技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue | 3.5+ | 组件化 UI 框架 |
| Vite | - | 构建工具 |
| Element Plus | - | UI 组件库 |
| Pinia | - | 全局状态管理 |
| Vue Router | 4 | 路由与角色守卫 |
| Axios | - | HTTP 请求，withCredentials |
| ECharts | - | 统计图表 |

### 2.1 前端目录结构

- `src/api/`：按模块封装的后端接口。
- `src/stores/`：Pinia store，管理用户会话、搜索状态。
- `src/views/`：按角色分目录的页面组件。
- `src/components/Layout/`：侧边栏 + 顶部通知栏布局。
- `src/utils/request.js`：Axios 实例与统一错误处理。

## 3. 后端技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Node.js | 24+ | 运行时 |
| Express | 4+ | Web 框架 |
| better-sqlite3 | 13+ | SQLite 驱动 |
| Sequelize | 6+ | ORM |
| bcryptjs | - | 密码哈希 |
| express-session | - | 服务端 Session |
| pdfkit | - | PDF 行程单 |
| exceljs | - | Excel 导出 |
| @fast-csv/format | - | CSV 导出 |
| node-cron | - | 定时任务（预留） |

### 3.1 后端目录结构

- `app.js` / `server.js`：应用与服务器入口。
- `config/`：数据库与 session 配置。
- `middleware/`：鉴权、角色校验、错误处理。
- `models/`：Sequelize 模型与关联。
- `controllers/`：HTTP 请求解析与响应封装。
- `services/`：业务逻辑层。
- `routes/`：路由挂载。
- `utils/`：统一响应、SQLite 兼容封装、PDF 辅助。
- `scripts/`：数据库初始化与示例数据。

### 3.2 SQLite 兼容封装

由于 Node.js 24 下 Sequelize 官方 sqlite3 预构建缺失，使用 `better-sqlite3` 并通过 `utils/sqlite3-wrapper.js` 适配 Sequelize 的 sqlite3 API：
- 参数占位符 `$n` 转 `?`。
- 跳过字符串字面内的占位符替换。
- 归一化数组参数以适配 better-sqlite3。

## 4. 鉴权设计

- 登录成功后写入 `req.session.user`。
- 受保护路由使用 `requireAuth` 校验 session。
- 角色路由使用 `verifyRole(...allowedRoles)` 校验角色。
- 前端 Axios 启用 `withCredentials: true`。
- 后端 CORS 配置 `credentials: true`。

## 5. 关键业务设计

### 5.1 库存扣减
- 下单时在事务中锁定 `seat_inventory` 行并扣减余座。
- 取消订单时回滚余座。

### 5.2 支付出票
- 模拟支付成功后创建 `payment` 记录，生成 `ticket` 记录。

### 5.3 选座值机
- 座位号按机型 `layout` JSON 生成。
- 起飞前 24 小时内方可值机。

### 5.4 退改签
- 退票按起飞前时间梯度退款。
- 改签扣减目标航班库存、恢复原航班库存，并更新客票与订单。

## 6. 部署方式

### 6.1 开发环境

```bash
cd 05-项目源代码/flight-system-backend
npm install
npm run db:init
npm run dev

cd 05-项目源代码/flight-system-frontend
npm install
npm run dev
```

### 6.2 生产构建

```bash
cd 05-项目源代码/flight-system-frontend
npm run build
```

将 `dist` 部署到静态服务器，后端使用 `npm start` 启动。

## 7. 扩展性

- 通过替换 `dialectModule` 可迁移至其他 SQLite 驱动。
- 各服务层独立，便于后续拆分为微服务。
