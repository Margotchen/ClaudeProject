# 接口文档

## 1. 接口约定

- Base URL: `http://localhost:3000/api`
- 响应格式：`{ code, message, data }`
- 分页响应：`{ code, message, data: { list, pagination: { page, pageSize, total } } }`
- 鉴权：cookie-based session，Axios 需设置 `withCredentials: true`

## 2. 认证模块

### POST /api/auth/login
- 功能：登录
- 请求体：`{ username, password }`
- 响应：`{ user: { id, username, realName, roleCode } }`

### POST /api/auth/logout
- 功能：登出

### GET /api/auth/profile
- 功能：获取当前登录用户信息
- 响应：`{ user: { id, username, realName, roleCode } }`

## 3. 航班模块

### GET /api/flights/search
- 功能：旅客查询航班
- 参数：`origin`, `destination`, `date`, `page`, `pageSize`
- 权限：公开 / 登录

### GET /api/flights
- 功能：航班列表（operator）
- 参数：`page`, `pageSize`, `keyword`

### POST /api/flights
- 功能：新增航班（operator）
- 请求体：`{ flightNo, departureAirportCode, arrivalAirportCode, plannedDuration }`

### PUT /api/flights/:id
- 功能：编辑航班（operator）

### DELETE /api/flights/:id
- 功能：删除航班（operator）

### GET /api/flights/schedules/list
- 功能：排班列表（operator）
- 参数：`page`, `pageSize`, `flightId`, `flightDate`, `status`

### GET /api/flights/schedules/:id
- 功能：排班详情（登录）

### POST /api/flights/schedules
- 功能：新增排班（operator）
- 请求体：`{ flightId, aircraftId, flightDate, departureTime, arrivalTime, economyPrice, businessPrice, firstPrice }`

### PUT /api/flights/schedules/:id
- 功能：编辑排班（operator）

### DELETE /api/flights/schedules/:id
- 功能：删除排班（operator）

### PUT /api/flights/schedules/:id/status
- 功能：更新航班状态（operator）
- 请求体：`{ status, delayMinutes, reason }`

## 4. 订单模块

### POST /api/bookings
- 功能：创建订单
- 请求体：`{ scheduleId, cabinClass, passengers: [{ name, idCard }], contactName, contactPhone }`
- 权限：passenger

### GET /api/bookings/my
- 功能：我的订单
- 参数：`page`, `pageSize`, `status`
- 权限：passenger

### GET /api/bookings/:id
- 功能：订单详情
- 权限：本人 / service / operator

### POST /api/bookings/:id/cancel
- 功能：取消待支付订单
- 权限：passenger

## 5. 支付模块

### POST /api/payments/simulate
- 功能：模拟支付
- 请求体：`{ orderId, payMethod, simulateSuccess }`
- 权限：passenger

### GET /api/payments/:orderId/status
- 功能：查询支付状态

## 6. 选座值机模块

### GET /api/checkin/seats/:orderId
- 功能：座位图
- 权限：passenger

### POST /api/checkin/select-seat
- 功能：选座
- 请求体：`{ ticketId, seatNo }`

### POST /api/checkin/checkin/:orderId
- 功能：值机

## 7. 退改签模块

### POST /api/refund-change/refund
- 功能：申请退票
- 请求体：`{ orderId, reason }`
- 权限：passenger

### POST /api/refund-change/change
- 功能：申请改签
- 请求体：`{ orderId, targetScheduleId, reason }`
- 权限：passenger

### GET /api/refund-change/my
- 功能：我的退改签
- 权限：passenger

### GET /api/refund-change/pending
- 功能：待处理退改签
- 权限：service

### PUT /api/refund-change/:id/process
- 功能：处理退改签
- 请求体：`{ status, remark }`
- 权限：service

## 8. 行程单模块

### GET /api/itineraries/:orderId/pdf

## 9. 航班动态模块

### GET /api/notifications/unread-count

## 13. 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 业务错误 / 参数错误 |
| 401 | 未登录 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
