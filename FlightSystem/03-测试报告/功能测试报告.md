# 功能测试报告

## 1. 测试环境

- 后端：Node.js 24，Express + SQLite
- 前端：Vue 3 + Vite，Chrome 浏览器
- 测试账号：passenger/pass123、service/svc123、operator/op123

## 2. 测试用例与结果

### 2.1 登录与权限

| 用例 | 步骤 | 预期结果 | 结果 |
|------|------|----------|------|
| 旅客登录 | 使用 passenger/pass123 登录 | 进入机票查询页 | 通过 |
| 角色越权 | 旅客访问 /operator/flights | 跳转首页 | 通过 |
| 未登录访问 | 直接访问 /passenger/orders | 跳转登录页 | 通过 |

### 2.2 航班管理

| 用例 | 步骤 | 预期结果 | 结果 |
|------|------|----------|------|
| 新增航班 | operator 填写航班信息保存 | 列表新增成功 | 通过 |
| 新增排班 | operator 选择航班、机型、日期保存 | 库存自动生成 | 通过 |
| 更新状态 | operator 将排班设为延误 | 状态变更，受影响的旅客收到通知 | 通过 |
| 删除排班 | operator 删除排班 | 排班移除 | 通过 |

### 2.3 机票查询与预订

| 用例 | 步骤 | 预期结果 | 结果 |
|------|------|----------|------|
