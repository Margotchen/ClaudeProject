# 缺陷清单

## 1. 已修复缺陷

| 编号 | 描述 | 原因 | 修复方式 |
|------|------|------|----------|
| 1 | better-sqlite3 v11 在 Node.js 24 下无法安装 | 缺少预构建二进制且构建工具不可用 | 升级至 better-sqlite3 ^13.0.3 |
| 2 | ESM 环境下 __dirname 未定义 | Vite 配置使用 CommonJS 全局变量 | 使用 `fileURLToPath(new URL('.', import.meta.url))` 替代 |
| 3 | bulkCreate 不返回自增 ID | 自定义 sqlite3-wrapper 未返回 lastID | 对需要 ID 的数据使用 create 循环 |
| 4 | 占位符替换误替换字符串字面量 | 正则替换未跳过引号 | 实现 `_replacePlaceholders` 状态机 |
| 5 | false/0 被当作无参数 | `_normalizeParams` 对 falsy 值判断错误 | 使用 `params === undefined \|\| params === null` |
| 6 | `.env.development` 代理配置错误 | 使用绝对 URL 绕过 Vite proxy | 改为 `/api` |

## 2. 已知缺陷 / 改进项

| 编号 | 描述 | 影响 | 计划处理方式 |
|------|------|------|--------------|
| 7 | 仅支持模拟支付，未接入真实支付渠道 | 生产环境不可用 | 后续接入支付宝/微信/Stripe SDK |
| 8 | Session 使用内存存储，重启后丢失 | 多实例部署受限 | 迁移至 Redis 或数据库存储 |
| 9 | 站内通知未推送到邮件/短信 | 用户触达率有限 | 接入邮件或短信网关 |
| 10 | 航班动态刷新依赖人工更新 | 自动化程度低 | 接入机场数据源或定时任务模拟 |
| 11 | 选座页面未做移动端适配 | 移动端体验不佳 | 增加响应式布局 |
| 12 | 缺少自动化单元测试与集成测试 | 回归成本高 | 补充 Jest + Supertest 测试用例 |

## 3. 结论

当前版本已完成所有核心功能开发并通过人工功能验证，满足毕业设计/课程项目演示需求。生产化部署前需处理内存 session、真实支付、外部通知等改进项。
