# 企业福利礼品申领管理系统 - 接口文档

## 1. 接口基础信息

- 基础地址：`http://localhost:3000/api`
- 请求格式：`application/json`
- 鉴权方式：`Authorization: Bearer <JWT Token>`
- 统一响应格式：
  ```json
  { "code": 200, "message": "...", "data": {} }
  ```

## 2. 认证接口

### 2.1 登录

- **POST** `/auth/login`
- 请求体：
  ```json
  { "username": "admin", "password": "admin123" }
  ```
- 响应：
  ```json
  {
    "token": "eyJhbG...",
    "user": { "id": 1, "username": "admin", "role": { "role_code": "admin" } }
  }
  ```

### 2.2 登出

- **POST** `/auth/logout`
- 需要鉴权

### 2.3 当前用户信息

- **GET** `/auth/userinfo`
- 需要鉴权

## 3. 用户管理（admin）

### 3.1 用户列表

- **GET** `/users?page=1&pageSize=10&keyword=`

### 3.2 新增用户

- **POST** `/users`
- 请求体：
  ```json
  {
    "user_no": "EMP002",
    "username": "zhangsan",
    "password": "123456",
    "real_name": "张三",
    "department": "技术部",
    "phone": "13800138000",
    "role_id": 1
  }
  ```

### 3.3 编辑用户

- **PUT** `/users/:id`

### 3.4 删除用户

- **DELETE** `/users/:id`

### 3.5 重置密码

- **PUT** `/users/:id/reset-password`
- 请求体：`{ "password": "newpassword" }`

## 4. 角色管理（admin）

### 4.1 角色列表

- **GET** `/roles`

### 4.2 角色详情

- **GET** `/roles/:id`

### 4.3 新增/编辑/删除角色

- **POST** `/roles`
- **PUT** `/roles/:id`
- **DELETE** `/roles/:id`

## 5. 礼品库管理（hr/admin）

### 5.1 礼品列表

- **GET** `/gifts?page=1&pageSize=10&keyword=&status=`

### 5.2 礼品详情

- **GET** `/gifts/:id`

### 5.3 新增礼品

- **POST** `/gifts`
- 请求体：
  ```json
  {
    "gift_name": "测试礼品",
    "specification": "规格",
    "stock": 100,
    "warn_stock": 10,
    "supplier_name": "供应商",
    "supplier_contact": "联系人",
    "supplier_phone": "13800138000",
    "image_url": ""
  }
  ```

### 5.4 编辑礼品

- **PUT** `/gifts/:id`

### 5.5 删除礼品

- **DELETE** `/gifts/:id`

### 5.6 上架/下架

- **PUT** `/gifts/:id/status`
- 请求体：`{ "status": 0 }` 或 `{ "status": 1 }`

### 5.7 调整库存

- **PUT** `/gifts/:id/stock`
- 请求体：`{ "stock": 200 }`

## 6. 福利活动管理（hr/admin）

### 6.1 活动列表

- **GET** `/activities?page=1&pageSize=10&keyword=&status=`

### 6.2 活动详情

- **GET** `/activities/:id`

### 6.3 新增活动

- **POST** `/activities`
- 请求体：
  ```json
  {
    "activity_name": "中秋节福利",
    "activity_type": "holiday",
    "start_time": "2026-08-20 00:00:00",
    "end_time": "2026-08-27 23:59:59",
    "limit_count": 2,
    "description": "中秋礼品申领"
  }
  ```

### 6.4 编辑活动

- **PUT** `/activities/:id`

### 6.5 删除活动

- **DELETE** `/activities/:id`

### 6.6 启停活动

- **PUT** `/activities/:id/status`
- 请求体：`{ "status": 3 }`（停用）或 `{ "status": 0/1 }`

### 6.7 配置活动礼品

- **PUT** `/activities/:id/gifts`
- 请求体：`{ "giftIds": [1, 2] }`

### 6.8 查看活动礼品

- **GET** `/activities/:id/gifts`

### 6.9 员工端可申领活动列表

- **GET** `/activities/available`
- 员工可访问

## 7. 收货地址管理

### 7.1 地址列表

- **GET** `/addresses`

### 7.2 新增地址

- **POST** `/addresses`
- 请求体：
  ```json
  {
    "receiver": "张三",
    "phone": "13800138000",
    "province": "广东省",
    "city": "深圳市",
    "district": "南山区",
    "detail_address": "科技园",
    "is_default": 1
  }
  ```

### 7.3 编辑地址

- **PUT** `/addresses/:id`

### 7.4 删除地址

- **DELETE** `/addresses/:id`

### 7.5 设为默认

- **PUT** `/addresses/:id/default`

## 8. 申领管理

### 8.1 提交申领

- **POST** `/apply`
- 请求体：
  ```json
  {
    "activityId": 1,
    "addressId": 1,
    "items": [
      { "giftId": 1, "quantity": 1 },
      { "giftId": 2, "quantity": 1 }
    ]
  }
  ```

### 8.2 修改申领

- **PUT** `/apply/:id`
- 请求体：`{ "addressId": 1, "items": [...] }`

### 8.3 取消申领

- **PUT** `/apply/:id/cancel`

### 8.4 我的申领列表

- **GET** `/apply/my-list?page=1&pageSize=10&status=`

### 8.5 申领详情

- **GET** `/apply/:id`

### 8.6 HR 申领列表

- **GET** `/apply/list?page=1&pageSize=10&activityId=&status=&keyword=`

## 9. 发货管理（hr/admin）

### 9.1 单条发货

- **PUT** `/deliver/:id`
- 请求体：
  ```json
  {
    "expressCompany": "顺丰速运",
    "expressNo": "SF1234567890"
  }
  ```

### 9.2 批量发货

- **PUT** `/deliver/batch`
- 请求体：`{ "ids": [1, 2], "expressCompany": "顺丰", "expressNo": "SFxxx" }`

## 10. 签收反馈

### 10.1 确认签收

- **PUT** `/sign/:id`
- 请求体：`{ "feedback": "礼品已收到" }`

### 10.2 反馈列表（hr/admin）

- **GET** `/sign/feedback?page=1&pageSize=10`

## 11. 统计看板（hr/admin）

### 11.1 Dashboard 数据

- **GET** `/statistics/dashboard`
- 响应：
  ```json
  {
    "stats": {
      "totalActivities": 10,
      "ongoingActivities": 3,
      "totalApplyCount": 120,
      "pendingDeliverCount": 5
    },
    "topGifts": [...],
    "departments": [...],
    "deliveryProgress": [...]
  }
  ```

## 12. 导出中心（hr/admin）

### 12.1 导出申领明细 Excel

- **GET** `/export/apply?activityId=&status=&format=xlsx`

### 12.2 导出申领明细 CSV

- **GET** `/export/apply?activityId=&status=&format=csv`

## 13. 状态码说明

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数错误或业务校验失败 |
| 401 | 未登录或 Token 无效 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
