# 企业福利礼品申领管理系统 - 部署手册

## 1. 环境要求

- Node.js >= 18（推荐 20 LTS 及以上）
- npm >= 9
- Git（可选）

## 2. 目录结构

```
c:\ClaudeProject\BenefitSystem
├── 01-PRD文档
├── 02-技术方案
├── 03-测试报告
├── 04-AI对话记录
└── 05-项目源代码
    ├── benefit-system-backend/
    └── benefit-system-frontend/
```

## 3. 后端部署

### 3.1 进入后端目录

```bash
cd 05-项目源代码/benefit-system-backend
```

### 3.2 安装依赖

```bash
npm install
```

依赖包含：
- express
- sequelize
- better-sqlite3
- jsonwebtoken
- bcryptjs
- node-cron
- exceljs
- fast-csv
- dotenv

### 3.3 环境变量配置

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

编辑 `.env`：

```env
PORT=3000
JWT_SECRET=your_jwt_secret_key_here
JWT_EXPIRES_IN=24h
DB_STORAGE=./data/benefit_system.sqlite
DB_LOGGING=false
```

> **注意**：生产环境请务必修改 `JWT_SECRET` 为强随机字符串。

### 3.4 初始化数据库

```bash
node scripts/init-db.js
```

该脚本会创建 SQLite 数据库文件并执行 `migrations/init-database.sql`，初始化表结构、角色、默认账号及示例礼品。

### 3.5 启动服务

开发模式：

```bash
npm start
```

生产模式（使用 pm2 等进程管理器）：

```bash
npm install -g pm2
pm2 start server.js --name benefit-system-backend
```

服务启动后，控制台输出：

```
数据库连接成功
服务已启动，端口: 3000
```

## 4. 前端部署

### 4.1 进入前端目录

```bash
cd 05-项目源代码/benefit-system-frontend
```

### 4.2 安装依赖

```bash
npm install
```

### 4.3 开发环境运行

```bash
npm run dev
```

默认访问地址：`http://localhost:5173`

Vite 代理已将 `/api` 请求转发到 `http://localhost:3000`。

### 4.4 生产构建

```bash
npm run build
```

构建产物位于 `dist/` 目录。

### 4.5 生产预览

```bash
npm run preview
```

### 4.6 静态部署

将 `dist/` 目录内容部署到 Nginx、Apache 或任意静态服务器，并配置反向代理：

```nginx
server {
  listen 80;
  server_name benefit.example.com;
  root /path/to/benefit-system-frontend/dist;
  index index.html;

  location /api {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }

  location / {
    try_files $uri $uri/ /index.html;
  }
}
```

## 6. 数据库迁移

开发阶段可使用 Sequelize 自动同步：

```bash
node -e "require('./models').sequelize.sync()"
```

生产环境请使用 `migrations/init-database.sql` 初始化，避免 `alter: true` 导致数据风险。

## 7. 常见问题

### 7.1 端口被占用

修改 `.env` 中的 `PORT`，或终止占用 3000 端口的进程。

### 7.2 better-sqlite3 安装失败

确保 Node.js 版本 >= 18，且系统具备 C++ 编译环境（Windows 通常可直接安装预编译包）。如仍失败，可尝试：

```bash
npm rebuild better-sqlite3
```

### 7.3 前端构建后接口 404

检查 Nginx/静态服务器是否正确配置了 `/api` 反向代理到后端服务。

## 8. 备份建议

定期备份数据库文件：

```bash
cp data/benefit_system.sqlite backup/benefit_system_$(date +%Y%m%d).sqlite
```

## 9. 安全建议

- 生产环境修改默认密码。
- 使用 HTTPS 部署。
- 将 JWT Secret 设置为随机长字符串。
- 限制数据库文件访问权限。
- 定期审查系统操作日志。
