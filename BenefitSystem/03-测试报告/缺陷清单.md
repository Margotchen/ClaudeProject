# 企业福利礼品申领管理系统 - 缺陷清单

## 1. 已修复缺陷

| 序号 | 缺陷描述 | 影响 | 修复方案 | 状态 |
|------|----------|------|----------|------|
| 1 | `sqlite3` 包在 Node 24 下无法安装 | 后端无法启动 | 切换为 `better-sqlite3` | ✅ 已修复 |
| 2 | `node-sqlite3-wasm` 运行时崩溃 | 数据库连接失败 | 放弃使用，改用 `better-sqlite3` | ✅ 已修复 |
| 3 | Sequelize sqlite 方言缺少 `OPEN_*` 常量 | 连接初始化失败 | 在 wrapper 中暴露常量 | ✅ 已修复 |
| 4 | Sequelize 需要 3 参数 Database 构造函数 | 连接报错 | 支持参数重载 | ✅ 已修复 |
| 5 | Sequelize 调用 `conn.serialize(callback)` 挂起 | 查询不执行 | 实现 `serialize`/`parallelize` | ✅ 已修复 |
| 6 | better-sqlite3 不支持 `$1, $2` 占位符 | UPDATE 语句语法错误 | `_prepare` 转换 `$N` → `?` 并按序取值 | ✅ 已修复 |
| 7 | better-sqlite3 结果缺少 `lastID`/`changes` | Sequelize 读取 undefined | 映射为 sqlite3 风格结果对象 | ✅ 已修复 |
| 8 | `all()`/`get()` 对非 SELECT 语句报错 | 部分查询失败 | 捕获异常并降级为 `run()` | ✅ 已修复 |
| 9 | 初始 SQL 中默认账号密码哈希错误 | 无法登录默认账号 | 重新生成 bcrypt 哈希并更新 | ✅ 已修复 |
| 10 | `vite.config.js` 使用 `__dirname` 触发 Vite 警告 | 构建警告 | 改为 `fileURLToPath` + `import.meta.url` | ✅ 已修复 |
| 11 | `alter: true` 同步因外键冲突失败 | 数据库初始化异常 | 开发阶段使用 `db.sequelize.sync()` | ✅ 已修复 |
| 12 | 前端 `request.js` 把 blob 导出响应当 JSON 拦截 | 导出中心提示失败 | 在拦截器中跳过 `responseType === 'blob'` 的响应 | ✅ 已修复 |
| 13 | 导出接口 `Content-Disposition` 中文头非法字符 | 后端返回 500 | 使用 RFC 5987 编码文件名 | ✅ 已修复 |
| 14 | 导出接口 `ids` 参数未校验，可产生 `NaN` SQL | 后端 500 | 严格解析并校验正整数 | ✅ 已修复 |
| 15 | 导出接口路由使用可选路径参数但读取 query | REST 语义混乱 | 改为 `/export/apply` 纯 query 入口 | ✅ 已修复 |
| 16 | CSV 空数据导出为 0 字节 | 空表无表头 | 空数据时手动补表头行 | ✅ 已修复 |
| 17 | 导出服务未防御 `row.items` 缺失 | 后端 500 | 使用 `(row.items || [])` 并补主表行 | ✅ 已修复 |
| 18 | 导出字段缺少“签收状态” | 不符合 PRD 字段清单 | 在 schema 中增加签收状态列 | ✅ 已修复 |
| 19 | 导出路由未挂载角色权限中间件 | 越权风险 | 添加 `verifyRole(['hr', 'admin'])` | ✅ 已修复 |
| 20 | 统计服务 count 查询串行、GROUP BY 不严谨 | 响应慢/严格模式 SQL 报错 | 并行化查询并补全 GROUP BY 字段 | ✅ 已修复 |
| 21 | 员工活动大厅未判断已申领状态 | 已申领员工仍可重复进入申领页 | `Hall.vue` 加载 `myApplyList` 并给出提示/跳转 | ✅ 已修复 |
| 22 | `ActivityDetail.vue` 未回填已申领数据 | 修改申领需重新选择 | 回填已有明细数量与默认地址，并增加覆盖确认 | ✅ 已修复 |
| 23 | 已结束/已停用活动仍可提交申领 | 业务规则被突破 | 增加 `isActivityClosed` 禁用输入与提交 | ✅ 已修复 |
| 24 | 申领管理页未展示收货地址快照 | HR 无法看到员工地址 | `ApplyManage.vue` 增加收货人/电话/地址列 | ✅ 已修复 |
| 25 | 批量发货路由被单条发货路由覆盖 | `/deliver/batch` 返回 404 | 调整路由顺序：`/batch` 置于 `/:id` 之前 | ✅ 已修复 |
| 26 | 批量发货未校验目标申领单状态 | 可能误操作已签收/已取消记录 | 在 `deliver.controller.js` 中校验全部待发货 | ✅ 已修复 |
| 27 | 修改申领未限制非待发货状态 | 已发货/已签收记录可被修改 | `apply.controller.js` 与 `apply.service.js` 增加状态校验 | ✅ 已修复 |
| 28 | 删除活动未处理关联申领记录 | 触发外键约束错误，删除失败 | 删除前校验申领记录数并给出明确提示 | ✅ 已修复 |
| 29 | 删除礼品未检查历史申领明细引用 | 触发外键约束错误 | 校验 `welfare_apply_item` 引用并提示下架 | ✅ 已修复 |
| 30 | 配置活动礼品缺少事务保护 | 异常时活动礼品被清空 | `setGifts` 使用 `sequelize.transaction` 包裹 | ✅ 已修复 |
| 31 | 设置默认地址非事务化 | 并发时可能出现多个默认地址 | `setDefault`/`create`/`update` 纳入事务 | ✅ 已修复 |
| 32 | 服务启动无条件执行 `sequelize.sync()` | 生产环境可能自动改表 | 生产环境跳过自动同步，改用 `npm run db:init` | ✅ 已修复 |
| 33 | 提交申领时对礼品重复查询 | 造成冗余数据库访问 | `validateApplyData` 返回 `giftMap` 供后续复用 | ✅ 已修复 |
| 34 | 数据库积累废测试数据 | 页面出现乱码/脏数据 | 新增 `scripts/cleanup-test-data.js` 与 `npm run db:cleanup` | ✅ 已修复 |

## 2. 已知问题

| 序号 | 问题描述 | 影响 | 建议处理方式 |
|------|----------|------|--------------|
| 1 | 前端生产构建部分 chunk 超过 500 kB | 首次加载稍慢 | 可通过动态导入进一步优化，当前不影响功能 |
| 2 | 高并发下 SQLite 写入会串行排队 | 大量并发申领时响应变慢 | 如需高并发，建议迁移至 MySQL/PostgreSQL |
| 3 | 未集成前端单元测试与 E2E 测试 | 回归验证依赖手工 | 后续可补充 Vitest + Playwright |
| 4 | 浏览器端 Excel/CSV 导出未进行实际下载验证 | 导出功能已接口验证 | 建议后续补充浏览器下载测试 |
| 5 | 图片资源使用占位图 URL | 演示环境可用 | 生产环境替换为真实图片或对象存储 |

## 3. 风险说明

- SQLite 为文件型数据库，不适合多节点部署；如需集群部署，必须迁移至服务端数据库。
- JWT Secret 目前通过 `.env` 配置，部署时需确保环境变量安全。

## 4. 结论

所有阻塞性缺陷均已修复，系统可正常运行。剩余问题多为优化项或后续可补充的测试工作，不影响当前版本交付。
