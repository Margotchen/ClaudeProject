2. Docker Hub 直连被阻断，已在 `C:\Users\91870\.docker\daemon.json` 配置镜像源（docker.m.daocloud.io / docker.1ms.run / hub.rat.dev），改配置后需重启 Docker Desktop
3. docker CLI 不在 PATH，脚本中使用全路径：`%LOCALAPPDATA%\Programs\DockerDesktop\resources\bin\docker.exe`

## 3. 数据库

- 库名：`online_class`（utf8mb4）
- 建表脚本：
  - [schema.sql](../05-项目源代码/class-server/src/main/resources/sql/schema.sql)：`sys_role` + `sys_user`
  - [schema2.sql](../05-项目源代码/class-server/src/main/resources/sql/schema2.sql)：`course` + `live_schedule`（含示例数据）
- 初始数据（4 角色 + 4 账号）由后端 `DataInitializer` 在首次启动时自动写入，无需手工插入
- 数据库密码通过环境变量覆盖：`MYSQL_PASSWORD`（默认 123456），不入库提交

## 4. 启动方式

一键启动（推荐）：

```
start-class.bat    # 拉起 MySQL（复用检测）+ class-server(8090) + class-web(5174)
stop-class.bat     # 停止前后端服务
```

手动启动：

```bash
# 后端
cd 05-项目源代码/class-server
mvn package -DskipTests
java -jar target/class-server-1.0.0.jar

# 前端
cd 05-项目源代码/class-web
npm install
npm run dev
```

## 5. Windows 环境注意事项

1. **项目路径含中文**（`05-项目源代码`）：Maven 必须指定编码，否则 `spring-boot:run` 会 ClassNotFoundException：
   ```
   MAVEN_OPTS="-Dfile.encoding=UTF-8 -Dsun.jnu.encoding=UTF-8"
   ```
   启动脚本中已内置；手动执行 mvn 命令时需自行设置。打包后用 `java -jar` 运行不受影响。
2. **bat 文件必须 CRLF 行尾**，否则 cmd.exe 执行乱码/报错。
3. **git bash 中 curl 发送中文 body 会变 GBK**，导致后端 JSON 解析 500——先将 JSON 写入文件，再用 `curl --data-binary @文件` 发送。
