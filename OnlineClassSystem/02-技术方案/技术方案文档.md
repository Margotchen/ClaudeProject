# 在线课堂直播平台 — 技术方案

> 归档位置：02-技术方案/技术方案文档.md

## 1. 技术选型

| 层级 | 技术选型 | 说明 |
| --- | --- | --- |
| 前端框架 | Vue3 + Vite + Pinia | 组件化开发，响应式布局，适配 PC 端 |
| UI 组件库 | Element Plus | 基础组件库，支持主题定制 |
| 样式方案 | SCSS + CSS 变量 + BEM 命名规范 | 可维护的样式架构，支持动态主题 |
| 动效方案 | CSS3 Transition/Animation + Vue Transition 组件 | 高性能交互动效，避免 JS 动画卡顿 |
| 后端 | Spring Boot 3.x + Spring Security + MyBatis-Plus | 成熟 Java 生态，快速开发业务接口 |
| 数据库 | MySQL 8.0 | 关系型数据库，存储用户、课程、直播、成绩等结构化数据 |
| 直播服务 | SRS 流媒体服务器 + WebRTC(WHIP) / HTTP-FLV | 支持高并发直播推拉流，自带录制能力 |
| 实时通信 | WebSocket | 实现弹幕、提问、白板等低延迟互动 |
| 鉴权方式 | JWT + Spring Security | RESTful 接口无状态鉴权 |
| 报表导出 | Apache POI | 生成 Excel/CSV 文件 |

> **方案修正说明**：原始规划中"网页端 RTMP 推流"不可行——浏览器无法直接推 RTMP。实际实现：讲师网页端走 WebRTC（WHIP 协议）推流至 SRS；如需 RTMP 推流则使用 OBS 等客户端。学生端拉流使用 HTTP-FLV / WebRTC。

## 2. 系统架构

前后端分离的分层架构，整体分为 5 层：

1. **表现层**：Vue3 前端页面，负责页面渲染与用户交互，通过 HTTP 请求调用后端接口，WebSocket 接收实时消息；内置主题系统与样式引擎，统一管理视觉规范
2. **网关层**：统一接口入口，负责路由转发、权限校验、限流控制
3. **业务服务层**：核心业务逻辑实现，包含用户服务、课程服务、直播服务、互动服务、作业服务、统计服务
4. **数据层**：MySQL 数据持久化，Redis 缓存热点数据
5. **基础设施层**：SRS 流媒体服务器、文件存储服务、定时任务调度

## 3. 核心数据库设计

### 3.1 用户与权限表（已实施）

- `sys_role`：角色表（id、role_code、role_name、description、sort、status）
- `sys_user`：用户表（id、username、password(BCrypt)、real_name、role_id、email、phone、avatar、status、theme、last_login_time、deleted 逻辑删除）

设计权衡：一人一角 `role_id` 直挂，不做用户-角色中间表；未来需多角色再升级。

### 3.2 课程与直播表（已实施 course / live_schedule）

- `course`：课程表（id、course_name、description、teacher_id、cover_url、syllabus、target_audience、status、deleted）
- `live_schedule`：直播计划表（id、course_id、live_title、start_time、duration、status[0未开始/1直播中/2已结束]、deleted）
- `live_session`：直播会话表（id、排课 ID、推流地址、实际开播时间、结束时间、录制文件地址）——第三期实施
- `playback_video`：录播视频表（id、课程 ID、直播会话 ID、视频地址、时长、上架状态）——第四期实施

### 3.3 互动与教学表（后续分期实施）

- `live_interaction`：互动消息表（id、直播间 ID、用户 ID、消息类型、内容、发送时间）
- `homework`：作业表（id、课程 ID、标题、内容、截止时间、创建人）
- `exam`：考试表（id、课程 ID、标题、题目 JSON、时长、创建人）
- `study_progress`：学习进度表（id、学生 ID、课程 ID、观看时长、作业完成率、考试平均分）

## 4. RESTful API 设计

### 4.1 认证模块（已实现）

- `POST /api/auth/login`：用户登录，返回 JWT 令牌
- `GET /api/auth/userinfo`：获取当前登录用户信息与权限
- `POST /api/auth/logout`：退出登录
- `PUT /api/user/theme`：保存用户主题偏好

### 4.2 用户模块（已实现，管理员限定）

- `GET /api/user/page`：用户分页查询（关键字 + 角色筛选）
- `POST /api/user` / `PUT /api/user/{id}` / `DELETE /api/user/{id}`：用户增改删（禁止删除自己）
- `PUT /api/user/{id}/status`：启用 / 禁用（禁用立即生效，禁止禁用自己）
- `PUT /api/user/{id}/password`：重置密码
- `GET /api/user/teachers`：讲师列表（建课时选择）
- `GET /api/role/list`：角色列表

### 4.3 课程模块（已实现）

- `GET /api/course/page`：课程分页（按角色控制数据范围）
- `POST /api/course` / `PUT /api/course/{id}` / `DELETE /api/course/{id}`（删除级联删排课）
- `PUT /api/course/{id}/status`：上架 / 下架

### 4.4 直播模块（排课已实现，推拉流第三期实施）

- `GET /api/live/schedule/page`：直播课表分页
- `POST /api/live/schedule` / `PUT /api/live/schedule/{id}` / `DELETE /api/live/schedule/{id}`
- `GET /api/live/push-url`：获取讲师推流地址（第三期）
- `GET /api/live/pull-url`：获取学生拉流地址（第三期）

### 4.5 作业与考试模块（第五期实施）

- `POST /api/homework`：布置作业
- `POST /api/homework/submit`：学生提交作业
- `POST /api/homework/grade`：讲师批改作业
- `GET /api/stats/study`：获取学习统计数据

## 5. 核心模块实现方案

1. **认证与权限**：JWT 无状态认证，hutool JWTUtil 签发/校验；过滤器每次请求查库校验用户 status（禁用立即生效）；后端 `@PreAuthorize` 静态角色鉴权（authorities 为 `ROLE_` + roleCode）；前端静态路由 + `meta.roles` 按角色过滤菜单，路由守卫拦截越权访问。
2. **数据权限**：课程/排课查询按角色过滤——讲师仅自己的课程、学生仅上架课程、班主任全量只读；写操作 `checkManageable` 校验归属，越权抛业务异常。
3. **直播模块（第三期）**：讲师端通过网页采集音视频与屏幕画面，以 WebRTC（WHIP）推流到 SRS；SRS 提供 HTTP-FLV/WebRTC 拉流地址供学生端播放。
4. **实时互动模块（第三期）**：基于 WebSocket 建立长连接，按直播间 ID 维护连接会话池；弹幕、提问、举手、投票消息通过服务端广播到同直播间所有客户端；电子白板基于 Canvas 实现，绘制坐标与动作序列化后通过 WebSocket 同步。
5. **录播模块（第四期）**：SRS 配置自动录制（DVR）策略，直播结束后生成 MP4 文件，同步生成录播记录。
6. **统计报表（第六期）**：定时任务离线聚合学习行为数据，生成统计快照；前端通过 ECharts 渲染可视化图表；导出接口基于 POI 生成 Excel/CSV 文件流。

## 6. 前端页面美化实现方案

### 6.1 主题系统（已实现）

- 基于 CSS 变量构建主题系统，浅色 / 深色主题通过切换根元素 `data-theme` 属性实现
- Element Plus 组件主题走 `html.dark` class + `dark/css-vars.css`，与自有变量双轨同步切换
- 用户主题偏好持久化到 localStorage 与后端 `sys_user.theme`，登录后以后端偏好为准（换设备恢复）
- index.html 内联脚本在挂载前应用主题，避免白闪

### 6.2 布局与组件美化

- 全局卡片统一样式：8px 圆角、轻微阴影、hover 时阴影加深与上移动效（BaseCard 组件）
- 侧边栏导航：选中项高亮背景 + 左侧色条，过渡平滑
- 按钮、表单控件统一交互态样式

### 6.3 交互动效规范

- 所有可交互元素 hover 过渡统一 `transition: all 0.3s ease`
- 页面进入淡入 + 上移，离开淡出 + 下移
- 弹窗缩放 + 淡入，时长 0.25s，ease-out
- 列表加载骨架屏占位

### 6.4 响应式适配

- 断点：1366px（小屏）/ 1920px（标准）/ 2560px（大屏）
- 小屏下侧边栏默认折叠，内容区卡片自动换行
- 直播教室页特殊适配：小屏下互动区收起为抽屉
