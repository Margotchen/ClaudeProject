# 在线课堂直播平台 — 产品需求文档（PRD）

> 版本：V1.1（含前端页面美化需求）
> 归档位置：01-PRD文档/产品需求文档.md

## 1. 产品概述

### 1.1 产品背景

面向教育机构数字化教学转型需求，搭建一站式在线直播授课平台，覆盖「教 - 学 - 练 - 测 - 评」完整教学闭环，支持多角色协同管理，兼顾专业教学能力与优质视觉体验，提升线上教学效率与学员学习体验。

### 1.2 核心目标

- 讲师：便捷完成直播授课、互动教学、作业考试布置与批改
- 学生：随时随地观看直播 / 录播、参与课堂互动、完成学习任务
- 班主任：监督班级学习进度，跟踪学员参与情况
- 管理员：全局课程、用户、数据的统一管控
- **体验目标**：打造统一、清爽、专业的前端视觉风格，优化交互流畅度，降低用户操作成本，提升平台品牌质感

### 1.3 输入输出定义

| 输入类型 | 输出类型 |
| --- | --- |
| 课程基础信息（名称 / 简介 / 大纲等） | 课程列表、课程详情页 |
| 直播音视频流、屏幕共享、白板操作 | 实时直播界面、电子白板同步画面 |
| 弹幕、提问、举手、投票等互动消息 | 课堂互动展示、投票结果统计 |
| 作业内容、考试题目、学生答卷 | 作业 / 考试列表、批改结果、成绩记录 |
| 学习行为埋点数据 | 学习进度、学习统计报表、数据看板 |
| 主题切换、窗口缩放操作 | 自适应布局、主题样式切换效果 |

## 2. 核心功能需求

### 2.1 课程管理

- 支持管理员 / 讲师创建课程，填写课程名、课程简介、关联讲师、上传课程封面、编辑课程大纲、设置适用人群
- 支持课程上下架、信息编辑、删除、搜索筛选
- 课程详情页展示完整课程信息、课表、录播列表

### 2.2 直播排课

- 讲师 / 管理员为课程安排直播场次，设置开播时间、时长、直播主题
- 学生端可查看个人课表，支持按日期、课程筛选
- 开播前 15 分钟系统自动提醒

### 2.3 直播授课

- 讲师端支持开启 / 关闭直播，提供摄像头、麦克风开关控制
- 支持屏幕共享、电子白板两种教学辅助工具
- 学生端实时观看直播，支持清晰度切换、全屏观看

### 2.4 互动功能

- 学生端：发送弹幕、文字提问、举手申请、参与课堂投票
- 讲师端：查看弹幕与提问、点名连麦、语音答疑、发起 / 结束投票、查看投票结果

### 2.5 课程录播

- 直播全程自动录制，无需手动操作
- 直播结束后自动生成录播视频，关联对应课程场次
- 学生可随时回放，支持倍速播放、进度拖拽

### 2.6 作业与考试

- 讲师布置课后作业、创建在线考试（支持选择题、判断题、简答题）
- 学生在线提交作业、完成考试答卷
- 讲师在线批改，打分并填写评语，成绩自动同步到学生学习档案

### 2.7 学习进度跟踪

- 自动统计学生直播 / 录播观看时长
- 记录作业完成状态、考试成绩
- 学生端可查看个人学习进度与完成情况

### 2.8 学习统计分析

- 按课程维度：统计总学习时长、学员参与度、平均成绩、成绩分布
- 按学生维度：统计个人学习总时长、作业完成率、考试平均分
- 支持多维度筛选与数据可视化展示

### 2.9 用户登录与权限

- 基于 RBAC 角色权限模型，支持 4 种角色：管理员、讲师、班主任、学生
- 不同角色登录后展示不同菜单与数据范围
- 支持账号密码登录、登录状态校验

### 2.10 统计报表与导出

- 提供运营数据看板，包含表格与柱状图、饼图等图表展示
- 支持核心数据导出为 Excel/CSV 格式

### 2.11 前端页面美化

**视觉规范统一**

- 建立统一设计语言，定义品牌色彩体系、字体规范、间距规范、阴影层级，契合教育行业专业、清爽、沉稳的调性
- 全局采用卡片式布局，区分内容层级，提升页面可读性

**核心页面美化**

- 登录页：品牌化视觉设计，增加动态背景与表单微动效
- 课程列表页：卡片式课程展示，封面圆角处理，hover 悬浮效果，信息层级清晰
- 直播教室页：沉浸式直播布局，视频区与互动区分区明确，控件半透明悬浮设计
- 学习统计页：可视化图表美化，配色柔和，数据卡片突出关键指标
- 个人中心页：信息分区展示，操作入口清晰

**交互动效优化**

- 全局按钮、卡片、导航项增加 hover 过渡动效，时长统一为 0.3s
- 页面切换、弹窗弹出增加平滑过渡动画
- 加载状态增加骨架屏与品牌加载动画，避免空白等待
- 表单输入、操作反馈增加微动效提示

**主题与适配**

- 支持浅色 / 深色双主题切换，满足日间 / 夜间不同使用场景
- 响应式布局适配 1366~2560 宽度 PC 屏幕，保证各尺寸下布局美观无错乱
- 高分辨率屏幕适配，支持 2x/3x 高清渲染
